# SAMPLE-LP — 客先ごとの採用LP（制作サンプル）

> 客先の採用漫画・採用アニメーションを使って作る、客先専用の採用LP（`/sample/{客先}/`）の仕様と作り方。1客先目はアソビシステム様（2026-10-16）。

## TL;DR

1. 1客先 = `sample/{客先}/`（`index.html`・`img/`・`theme.css`・動画）。部品の形は共通の `css/sample-lp.css`・`js/sample-lp.js`、客先ごとに変えるのは色（`theme.css`）と中身だけ
2. **掲載許諾が取れるまで公開しない**（push しない・サイトから導線を張らない）。公開後も `noindex`・sitemap に載せない・上部に「制作サンプル」の帯
3. 客先から届くのは画像のLP案だけのことが多い。絵は LP案から切り出して **Real-ESRGAN（アニメ絵用）で4倍** にし、焼き込まれた文字・ボタンは消して HTML で載せ直す（§4）

## 2. ページの決まり

- **制作サンプルの帯**（`.slp-samplebar`）: 最上部に「このページは、ビズ採用が制作した採用LPのサンプルです。掲載している募集要項などの内容はイメージです。」＋「ビズ採用トップへ」。最下部にも制作元の表示（`.slp-credit`）と「採用LPの制作を相談する」
- **検索に出さない**: `<meta name="robots" content="noindex, nofollow">`。sitemap.xml に追加しない（[../content/SEO.md](../content/SEO.md) §5）
- **ボタンの行き先**: 「エントリーする」は客先の応募先ではなく、ビズ採用のお問い合わせ `../../contact.html?source=sample-{客先}`（`js/main.js` が「参照ページ: sample-{客先}」を問い合わせ本文に添える）。「3分でわかる私たち」はページ内の動画 `#movie`
- **ヘッダー・フッターは客先のもの**（ビズ採用の `.rx-nav` / 固定CTA は出さない。`style.css` / `tokens.css` も読まない）
- LP案に無い文言（FAQ の回答など）は、**LP案に書かれている内容だけで作る**。書かれていないこと（選考期間など）は「選考の中でご案内します」にとどめる
- ブランドボイスは本体と同じ（絵文字禁止・「Webtoon」と書かない・AI混在比率を書かない）。アイコンはインライン SVG のスプライト（`<symbol>`）

## 3. 部品（css/sample-lp.css・js/sample-lp.js）

- クラスは `.slp-`。色は `--slp-*`（`:root` に既定値、客先の `theme.css` が `.slp` で上書き）
- **絵の上に文字を重ねる所**（ヒーロー `.slp-hero`・最後のCTA `.slp-cta`）: 絵の箱に `container-type: inline-size` を付け、位置は絵に対する %、文字とボタンの大きさは `cqw`（絵の幅に比例）。絵の外側はぼかした同じ絵（`__backdrop`）で埋める
  - ヒーローの幅は「画面の高さに収まる幅」まで（`(100svh − ヘッダー − 帯) × 絵の縦横比`、760〜1280px）。最後のCTAは 1440px まで
  - スマホ（≤768px）は重ねずに、絵の下に説明文とボタンを並べる。ヒーローは絵の右下（ボタンを消した跡）にだけ暗いグラデーションを掛けてなじませる
- **区切りの帯**（`.slp-band`）: 手書きの一言は絵の一部。スマホは高さ116pxに切り、左側（一言の部分）を見せる
- **動画**（`.slp-movie__player`）: `preload="none"`＋サムネイル。JS が動くときは再生前の操作バーを隠し、中央の再生ボタンと再生時間（`.slp-movie__time`）だけを見せる。再生したら操作バーを出し、ボタンと時間を消す
- **漫画の読み画面**（`<dialog class="slp-mv">`）: `[data-manga-open]`（コマ全体・「続きを読む」）で開く。ページ画像は HTML に `loading="lazy"` で置き、開くまで読み込まない。閉じ方はホームの `js/works-viewer.js` と同じ（× / 最後の「閉じる」/ Esc / 左右の暗い所 / スマホの「戻る」）。最後に「エントリーする」も置く
- **FAQ**: `<details>`（JS なし）。＋が開くと × に回る
- **メニュー**: 三本線で開閉（Esc・外側・リンクで閉じる）。全幅で三本線（LP案どおり）
- ブレークポイントは [DEVICE-RULES.md](DEVICE-RULES.md) §3 と同じ。320 / 768 / 1024 / 1440 / 1920px で確認済み（2026-10-16・横はみ出しなし）

## 4. 素材の作り方（LP案が画像しかないとき）

作業はリポの外（作業用フォルダ）で行い、できた WebP だけを `sample/{客先}/img/` に置く。LP案・原本の動画/PDFは `docs/private/`（コミットしない）。

1. **測る**: LP案に方眼を重ねて、絵ごとの切り出し範囲と「消す文字・ボタン」の範囲を測る
2. **切り出して消す**（`tools/sample-lp/{客先}/make_clean.py`）: HTML で載せ直す説明文・ボタンを消す。文字は線だけをマスクにし（明るい文字/暗い文字で判定）、ボタンは pill 形をマスクにする。穴埋めは OpenCV contrib の `cv2.xphoto.inpaint(…, INPAINT_FSR_BEST)` が最も自然（Telea は筋が出る）。穴埋め部は色差だけぼかして周囲になじませる
   - **手書きの一言・メモ・漫画のコマの文字は消さずに絵として残す**（手書き風フォントは雰囲気が合わなかった）。読み上げ用に `<h1 class="slp-vh">` と `alt` に同じ文言を入れる
3. **4倍にする**: Real-ESRGAN（`realesrgan-ncnn-vulkan`・macOS 版・M1 の GPU で動く）の `realesrgan-x4plus-anime` モデル。`-i work/clean -o work/up4 -n realesrgan-x4plus-anime`。比べた中で線と文字がいちばんきれい（`realesr-animevideov3` の2倍より上）
4. **仕上げ**（`make_final.py`）: 表示の最大幅の約2倍に縮小（ヒーロー・帯・CTA は 1920/960、コマは 1600/800 など）。ロゴは白地から2色の不透明度を逆算して透過にする。動画サムネイルは**本編から字幕の無いフレーム**を切り出し、LP案の手書き文字を背景から抜いて合成する
5. **書き出し**: `cwebp -q 80 -m 6 -sharp_yuv`（ロゴは `-q 95 -alpha_q 100`）。`<img width height>` は実寸
6. **漫画**: PDF は `swift tools/sample-lp/pdf2png.swift <PDF> <出力> 1.8`（PDFKit・追加インストール不要）→ `cwebp -q 80`。白紙ページが混ざることがあるので目で確認する
7. **動画**: `ffmpeg -vf scale=1280:-2 -c:v libx264 -preset slow -crf 27 -c:a aac -b:a 112k -movflags +faststart`（2分26秒 → 14.5MB）。GitHub の上限（1ファイル100MB）に注意
